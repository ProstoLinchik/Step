# Автотесты интернет-магазина на Page Object

Финальный проект курса [«Автоматизация тестирования с помощью Selenium и Python»]: автотесты для учебного интернет-магазина [selenium1py.pythonanywhere.com](http://selenium1py.pythonanywhere.com/), написанные с помощью паттерна Page Object.

## Что проверяют тесты

- гость и зарегистрированный пользователь могут добавить товар в корзину: название в сообщении совпадает с товаром, стоимость корзины равна цене;
- гость может перейти на страницу логина с главной страницы и со страницы товара;
- корзина, открытая из шапки сайта, пуста у нового гостя;
- отрицательные проверки: сообщение об успехе не появляется без добавления товара.

## Структура

```
pages/
    base_page.py      общие методы для всех страниц: переходы по шапке, ожидания, проверки
    basket_page.py    страница корзины
    locators.py       все селекторы, по классу на каждую страницу
    login_page.py     страница логина и регистрации
    main_page.py      главная страница
    product_page.py   страница товара
conftest.py           фикстура browser и параметр --language
test_main_page.py     тесты главной страницы
test_product_page.py  тесты страницы товара
```

## Запуск

```bash
pip install -r requirements.txt
pytest -v --tb=line --language=en -m need_review
```

- `--language` задаёт язык интерфейса (по умолчанию `en`);
- `-m need_review` запускает тесты, отобранные для рецензии. Без этого параметра запустятся все тесты.

Тесты зарегистрированного пользователя при каждом запуске регистрируют нового пользователя с уникальным адресом.
