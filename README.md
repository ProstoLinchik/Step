# Auto Tests for Stepik UI Course (Selenium + PyTest)

Проект с автотестами на Python + Selenium для учебного интернет-магазина.
Реализован паттерн Page Object Model (POM).

## Установка и запуск

1. Клонировать репозиторий:
   git clone <ссылка_на_репозиторий>

2. Установить зависимости:
   pip install -r requirements.txt

3. Запустить тесты:
   pytest -v --tb=line test_product_page.py
